# Rubric graded question behaviour (qbehaviour_rubricgraded)

Manual grading with a rubric. The grader picks a level for each rubric
criterion, and the mark is calculated from the points of the chosen levels.
The choices are stored with the question attempt, so they are regraded, backed
up, and shown in the response history.

This behaviour is not offered as a quiz setting. It is used by question types
that have a rubric, such as the Essay with rubric question type
(`qtype_essayrubric`). See the README of that plugin for how the plugins fit
together.
